# Idee per sviluppi successivi

La [roadmap della base](docs/roadmap.md) è conclusa con approvazione del 26 ottobre 2026. Le idee sotto non sono requisiti della base né decisioni di implementazione. Elo resta rinviato; ulteriori cambiamenti seguono R00 del regolamento 1.6.

### Set Base:

110-120 carte totali
ognuna con la sua rarità

Del Set Base fanno parte 7 personaggi, usati in qusto modo:
- 2 starter deck base, con due personaggi semplici che mostrino le meccaniche base di gioco
- 3 starter deck "premium", sbloccabili o acquistabili in seguito, con meccaniche più avanzate
- altri due personaggi trovabili nei booster packs, per costruirci mazzi personalizzati

Per ogni personaggio, il Set deve contenere almeno tre carte legate a loro e altre che si sposano bene con la loro strategia. Anche le carte Last Resort possono essere legate a un personaggio se il flavour e la meccanica di gioco si sposa bene. Le altre carte devono essere giocabili da tutti i personaggi, generiche

Provare a creare tutte le carte e poi playtestare estensivamente per rendere il gioco il quanto più possibile bilanciato?
