# C4-5b — Dopo, catture del 5 novembre 2026

Client con le scelte del proprietario applicate: A generale, B di calata e invito singolo di scarto. Edge su Windows, server locale e SQLite temporaneo; partite effettive, non fixture della scena. Le sole righe del log admin e l’account ADMIN sono sintetici. Le schermate di errore/preparazione sono provocate dichiaratamente ritardando/bloccando le richieste delle immagini nel browser. Nessun codice client/server modificato per le catture.
