SB-24 · Revisione di nomi, flavour, illustrazioni e rarità

Come si usa. Per ogni voce a sinistra c'è il valore attuale, a destra la proposta: cambia quello che non ti piace, scrivi una nota, segna Ok o Da rivedere. Il testo stampato è solo contesto (lo rifà SB-25). Salva (Chrome o Edge) scrive il file : la prima volta scegli quel file nella cartella del repository, poi la pagina lo ricorda. Con altri browser usa Esporta e salva il file scaricato sopra quello del repository. Su un altro PC, dopo git pull, apri la pagina e premi Apri sullo stesso file (oppure rigenera la pagina: python docs/design/set-base/sb-24/genera-revisione.py). Le modifiche non salvate restano anche nel browser, come rete di sicurezza.
